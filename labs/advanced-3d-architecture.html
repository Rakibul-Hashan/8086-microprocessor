Official Intel dual-unit pipeline mapping

The 8086 features two decoupled units operating simultaneously: the Bus Interface Unit (BIU) and the Execution Unit (EU).

BIU (Top Half)

  • Memory Interface: Generates bus cycles for memory/IO
  • Σ Adder: Sums (Segment × 16) + Offset
  • Segment Registers: ES, CS, SS, DS, and IP
  • 6-Byte Queue: Prefetches opcode bytes via C-Bus
  • B-Bus: Feeds segment base addresses to Σ adder

EU (Bottom Half)

  • Control System: Decodes opcode from Queue byte 1
  • A-Bus: Main 16-bit communication highway
  • 16-bit ALU: Executes arithmetic and boolean logic
  • Operands / Flags: Stores 9 condition status flags
  • EU Registers: AX, BX, CX, DX, SP, BP, SI, DI
Accurate Bus Arrows Legend

• B-bus: Upward arrow to left input of Σ adder.
• C-Bus: Horizontal line across top, turning down with arrow into Queue Byte 6.
• Queue to Control System: Downward arrow into decoder.
• A-Bus to ALU: Two downward arrows into left and right ALU operands.
• ALU to A-Bus: Output arrow turning right into the vertical trunk of A-Bus.
• Bidirectional (↕): Double-headed arrows between IP & A-Bus, EU registers & A-Bus, and Flags & A-Bus.
