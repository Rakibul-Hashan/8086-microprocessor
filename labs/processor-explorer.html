8086 Internal Architecture & Registers

The 8086 features a 20-bit address bus giving access to 1 Megabyte (1,048,576 bytes) of physical memory space. Because internal registers are 16 bits wide, memory is calculated using a Segment:Offset formula:
Physical Address = (Segment Register × 16) + Offset Register
Segment (Shifted Left 4-Bits / x16): 10000 H
+ Offset Value: 00200 H
20-Bit Physical Address: 10200 H
Binary: 0001 0000 0010 0000 0000

Bus Interface Unit (BIU)

External Bus Ops
  • Handles all instruction fetching, memory read/write, and I/O bus operations.
  • Contains the 6-Byte Instruction Queue for pipelining pre-fetched code.
  • Houses Segment Registers (CS, DS, SS, ES) and Instruction Pointer (IP).
  • Generates 20-bit physical addresses using internal dedicated adder circuit.

Execution Unit (EU)

Internal Execution
  • Decodes and executes instructions fetched from the BIU instruction queue.
  • Contains the 16-bit Arithmetic Logic Unit (ALU).
  • Houses General Purpose Registers (AX, BX, CX, DX) and Index/Pointers (SP, BP, SI, DI).
  • Maintains the 16-bit FLAGS Register (Status & Control Flags).
